# GTO 翻前实验室 · Preflop Lab

练习德州扑克翻前 GTO 决策的网页工具：按位置和行动线出题，答完立即对照 GTO 频率；可以像求解器一样浏览、编辑 13×13 策略矩阵；附带一个能在浏览器里实时计算的单挑翻前求解器。纯前端实现，构建后是一个可离线使用的单文件 HTML。

```bash
cd gto-preflop
npm install
npm run dev        # 本地开发：http://localhost:5173
npm run build      # 生成 dist/gto-preflop-lab.html（单文件，双击即可打开）
npm test           # 单元测试（范围记法、胜率表、决策树、训练评分、求解器）
npm run typecheck
```

## 四个页面

| 页面 | 做什么 |
| --- | --- |
| **训练** | 随机发一个场景和一手牌（牌桌上显示位置、下注、底池和底池赔率），你选弃牌 / 跟注 / 加注 / 全下，立刻看到这手牌的 GTO 频率、对抗对手范围的胜率，以及整个场景的范围图。可以按场景（开池、面对开池、面对 3-Bet、面对 4-Bet、面对 5-Bet）和位置筛选。 |
| **范围** | 求解器风格的策略浏览器：13×13 矩阵按行动频率分色，填充高度表示手牌到达此处的比例；图例显示每个行动占多少组合，点图例只看某个行动的手牌；可以沿着行动线一路往下看。**可编辑**：用画笔涂抹，或粘贴求解器导出的范围记法，训练会立即使用你的版本。 |
| **求解器** | 单挑翻前求解器（CFR+，在后台线程运行）：设置有效筹码、加注尺度、前注、单挑或盲注对抗，几百毫秒到几秒算出均衡策略，显示可剥削度的收敛曲线、每个决策点的范围和每手牌各行动的期望值，并可以直接用结果做训练（评分时额外显示 EV 损失）。 |
| **统计** | 总正确率、连对、按场景 × 位置的正确率热力图、最需要加强的场景、最近答错的题，一键重练错题。记录保存在浏览器本地。 |

快捷键：`F` 弃牌、`C` 跟注、`R` 加注 / 3-Bet / 4-Bet、`A` 全下、`1`–`4` 按按钮顺序、`空格` 下一手。

### 评分

- 频率最高、或频率 ≥ 50% 的行动：**正确**
- 20%–50%：**可以（混合策略）**，也算答对
- 5%–20%：**不够准确**；低于 5%：**错误**
- **随机数模式**：按"全下 → 加注 → 跟注 → 弃牌"的顺序把频率排在 0–99 上，随机数落在哪一段，哪个行动才算对。用来练习按频率执行混合策略。
- **边缘牌优先**（默认开启）：多出范围边缘和混合频率的手牌，一眼就能判断的牌（如 UTG 的 72o）出现得少。

## 内置的 6 人桌策略库

6 人桌现金局、100bb、开池 2.5bb（小盲 3bb），共 65 个决策点：

- 开池（UTG / HJ / CO / BTN / SB）
- 面对开池：弃牌 / 跟注 / 3-Bet（后位 3-Bet 到 7.5，小盲 11，大盲 12，大盲对小盲 9）
- 开池后面对 3-Bet：弃牌 / 跟注 / 4-Bet（无位置 20，有位置 25，小盲对大盲 22）
- 3-Bet 后面对 4-Bet：弃牌 / 跟注 / 全下
- 4-Bet 后面对全下：弃牌 / 跟注

范围参照主流求解器在这一设定下的解整理，混合频率精确到 5%–10%，写在 [`src/data/sixmax.ts`](src/data/sixmax.ts)，用的是常见的范围记法，便于核对和修改。它是**近似**的：只覆盖单挑行动线（跟注后不考虑身后玩家的挤压和超跟），小盲只加注不平跟，面对 3-Bet / 4-Bet 的范围按位置关系分组共用。如果你有自己求解器导出的范围，可以在"范围"页逐个场景粘贴进去替换。

后续节点的范围由前面的行动自动推出：例如"CO 开池后面对 BTN 3-Bet"里，每手牌的权重就是它在 CO 开池中的频率。编辑了前面的场景，后面的场景会跟着变。

## 求解器的模型

- 博弈树：小盲（加注 / 全下 / 弃牌）→ 大盲（跟注 / 3-Bet / 全下 / 弃牌）→ 小盲（跟注 / 4-Bet / 全下 / 弃牌）→ 大盲（跟注 / 全下 / 弃牌）→ 面对全下（跟注 / 弃牌）。加注额超过有效筹码 45% 的那一级去掉；有效筹码超过 40bb 时，只在不能再做常规加注的地方提供全下，和常见求解器的树一致。
- 169 个起手牌类别两两对局，按互不冲突的组合对数量加权（考虑卡牌移除）。
- **全下被跟注**：按两手牌的真实全下胜率结算。胜率表由 [`scripts/gen-equity.mjs`](scripts/gen-equity.mjs) 用蒙特卡洛预先算好（每对 10 万次，误差约 ±0.2%），所以"只推或弃"模式得到的是精确的纳什均衡（筹码 EV，不含 ICM）。10bb 时小盲约推 58%、大盲约跟 37%，与公认的推弃表一致（见测试）。
- **加注被跟注、进入翻牌**：不往下求解翻后，而是用权益实现模型估算底池份额——没有位置的一方吃亏、胜率领先的一方多实现、同花连张更好实现，筹码越浅（SPR 越低）越接近直接按胜率分底池。所以深筹码的结果是近似值，适合理解趋势（例如位置、筹码深度、加注尺度怎样改变范围）。
- 输出的可剥削度是双方最佳应对的平均收益（mbb/手），用来判断是否收敛。

## 项目结构

```
src/
  poker/       牌与 169 个起手牌类别、范围记法解析与压缩、全下胜率表
  data/        6 人桌策略库（sixmax.ts）与生成的胜率表（equity.ts）
  engine/      决策树（sixmax.ts）、求解器（solver.ts + 后台线程）、出题与评分（trainer.ts）、
               训练记录（stats.ts）、范围导入导出（rangeIO.ts）
  ui/          Preact 界面：牌桌、13×13 矩阵、四个页面、设置
scripts/
  gen-equity.mjs  重新生成胜率表：npm run gen:equity [-- 样本数]
  inline.mjs      把构建产物内联成单个 HTML（以及用于发布为 Artifact 的版本）
tests/         Vitest 单元测试
```

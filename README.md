# 尖塔重铸 · Spire Reforged

致敬《杀戮尖塔 2》（Slay the Spire 2）的网页版卡牌构筑 Roguelike 同人作品。纯前端实现，构建后是一个可离线游玩的单文件 HTML。

## 游玩

```bash
npm install
npm run dev        # 本地开发：http://localhost:5173
npm run build      # 生成 dist/spire-reforged.html（单文件，双击即可游玩）
```

操作方式：

- 拖动卡牌到敌人身上打出，或先点击卡牌、再点击目标
- 无需目标的牌：点击两次，或拖到手牌区上方
- `E` 结束回合，`1`–`9` 选牌，`Esc` 取消
- 鼠标悬停（或右键 / 长按）可查看卡牌关键词、敌人意图、能力与遗物说明
- 横屏和竖屏（手机）都可以玩，进度自动保存在浏览器本地

## 内容

| 类别 | 内容 |
| --- | --- |
| 角色 | 《杀戮尖塔 2》抢先体验版的五名角色：铁甲战士（力量 · 消耗）、静默猎手（中毒 · 小刀 · 弃牌）、**储君**（星辰 · 铸造君王之刃）、**亡灵契约师**（召唤奥斯提 · 灾厄 · 灵魂）、故障机器人（充能球 · 集中） |
| 卡牌 | 约 360 张：铁甲战士 75、静默猎手 73、储君 49、亡灵契约师 47、故障机器人 72，另有无色牌、诅咒与状态牌 |
| 地图 | 三幕：第一幕随机为蔓生密林或地下船坞，之后是嗡鸣蜂巢、荣光之巅；按《杀戮尖塔》规则生成的 15 层分支地图 |
| 敌人 | 68 种，含 13 场精英战与 12 名首领（每幕随机遇到 1 名） |
| 先古之民 | 每幕开始时出现（涅奥、奥罗巴斯、帕埃尔、特兹卡塔拉、诺努佩佩、瓦库、达尔夫），三选一的祝福，部分有代价 |
| 附魔 | 锋锐、坚固、迅捷、沉稳、耐心、高效、回响、充沛、守护、淬毒 |
| 其他 | 140 余件遗物、43 种药水、22 个随机事件、商店、休息处、宝箱、首领遗物、进阶 0–10、卡牌图鉴、合成音效 |

## 项目结构

```
src/
  core/            随机数（可存档的种子 RNG）、工具函数
  game/            纯逻辑层，不依赖 DOM
    combat.ts      战斗引擎：行动队列、伤害结算、能力钩子、选择暂停
    run.ts         一局游戏：地图、房间流程、奖励、商店、存档
    map.ts         地图生成
    bot.ts         自动对战机器人（测试 / 平衡性模拟）
    orbs.ts        故障机器人的充能球
    content/       全部游戏内容（卡牌、能力、遗物、药水、敌人、事件、先古之民、附魔）
  ui/              Preact 界面：按屏幕缩放的舞台、各个场景、特效与音效
tests/             Vitest：内容完整性、规则单元测试、机器人完整流程模拟
scripts/inline.mjs 把构建产物内联为单个 HTML
```

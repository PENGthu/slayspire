# 方舟动物园 · 网页同人版

桌游《方舟动物园》（Ark Nova）的网页还原版。纯前端实现，构建后是一个可离线游玩的单文件 HTML。

## 游玩

```bash
cd ark-nova
npm install
npm run dev        # 本地开发：http://localhost:5173
npm run build      # 生成 dist/ark-nova.html（单文件）
```

在线游玩：<https://pengthu.github.io/games/ark-nova/>。
更新线上版本：构建后把 `dist/ark-nova.html` 复制到 `PENGthu.github.io` 仓库的 `games/ark-nova/index.html`（图标与 `manifest.webmanifest` 一起复制），推送到 `master`。

- 1–4 人（另有 5 人扩展玩法，休息轨 19 格）：每个座位可以是人类或 AI（简单 / 普通 / 困难）；多名人类玩家同屏轮流时，换人前会遮住手牌
- 联机对战：一人建房，其他人打开邀请链接（`#join=房间号`）用各自的设备入座，空位可以交给 AI；见下文「联机」
- 1 人为单人挑战（原版单人规则）：6 轮，每轮 7 / 6 / 5 / 4 / 3 / 2 个回合，每轮结束休息；可选起始吸引力（20 入门 … 0 专家），最后得分 ≥ 0 即获胜
- 进度自动保存在浏览器本地；没有抽到新牌之前可以撤销
- 支持电脑与手机（手机上分页显示动物园、手牌、公共区、玩家和日志）

## 规则与卡牌还原

复刻原作基础游戏的规则、地图与卡牌功能：

- 5 张行动卡（动物、建造、卡牌、协会、赞助）按位置决定强度，用后回到 1 号位；I / II 两面的数值按原版行动卡；X 标记
- 升级来源：保护点数 2（或改拿协会工人）、声望 5、第 2 个合作动物园、第 2 所大学
- 10 张原版地图（0、A、1–8）：平顶六边形布局、水域、岩石、II 格、放置奖励，以及观景塔、户外区、商港、公园餐厅、研究所、冰淇淋店、好莱坞山等地图能力；地图左侧 7 个玩家标记（支持保护项目时拿走，获得露出的奖励，紫色的每次休息再给一次）
- 建筑：标准围栏 1–5 格、售货亭、凉亭、儿童动物园、爬行馆、大型鸟舍（原版形状与容量），赞助卡的专属建筑
- 128 张动物：体型、费用、图标、水域 / 岩石要求、声望 / 图标 / 合作动物园 / 升级条件、吸引力 / 保护点数 / 声望，以及原版的全部能力关键词（冲刺、狩猎、洞察、抢夺、助推、聪慧、群猎、代表动物、育儿袋、日光浴、毒液、绞杀、催眠、跳跃、掘地、炫耀、抗性、主张、统治、拾荒、机灵、高声呼唤、群居、赞助磁铁、掠夺、决心、开屏、萌宠、行动、倍增），单人模式按原版替换
- 64 张赞助卡：等级、条件、图标、专属建筑，以及立即 / 触发 / 收入 / 终局效果
- 32 个保护项目（12 个基础项目 + 放归野外、繁育计划、水 / 岩石 / 大小型动物 / 研究项目）与 11 张终局计分卡
- 协会：声望、合作动物园（第 2 / 3 / 4 个的奖励）、大学（三种）、保护项目、捐款；已占用的任务需要 2 名工人
- 声望轨奖励（卡牌行动升级前最高 9）、保护点数轨（2 / 5 / 8 / 10，奖励板块）、原版收入表与计分换算
- 休息：弃牌到手牌上限、清除毒液 / 绞杀 / 倍增标记、工人回收、展示区轮换、各种收入
- 终局：吸引力 + 保护点数换算分 ≥ 100 时触发，其他玩家再走 1 回合；得分 = 两个标记交错的距离

卡牌文字由本作重新撰写，插图为自绘（按大洲、种类、水域 / 岩石需求生成的小风景，赞助卡画出专属建筑的形状），动物用表情符号表示。原版卡牌数据整理脚本见 `scripts/data/`。

## 联机

网页仍是静态文件，联机消息经免费的公共 MQTT 服务器（WebSocket）转发：EMQX、HiveMQ、Mosquitto 几条线路，建房时同时连接、用最快的那条，房间号的第一个字符记录线路。

- 房主权威：房主的浏览器保存局面、运行 AI、检查每一步；其他玩家把走法发给房主，本地先行显示，房主按顺序广播（序号 + 局面指纹），各端用同一个规则引擎重放
- 丢消息、断线重连、指纹对不上时，从房主发布的整局快照（gzip，保留消息）重新同步；房主每次打开页面有新的 `epoch`，刷新后其他人自动对齐
- 撤销由房主执行：只能撤销自己刚走的一步，且之后没有翻开新信息
- 掉线的玩家可以由房主交给 AI 托管，回来后点「我回来了」
- 开局选牌、休息弃牌等排队的选择可以提前选好，轮到时自动提交
- 所有人都持有完整局面（包括别人的手牌），适合朋友之间游玩；公共服务器上的消息任何知道房间号的人都能看到

本地测试可以用 `?mqtt=ws://localhost:端口` 指定自己的 MQTT 服务器。

## 项目结构

```
src/
  core/rng.ts       可存档的种子随机数
  game/             纯逻辑层，不依赖 DOM
    types.ts        状态与卡牌类型（状态是纯 JSON）
    engine.ts       规则引擎：所有变化都通过 apply(state, move)，决定与自动步骤放在同一个栈上
    effects.ts      卡牌效果：动物能力、赞助卡（立即 / 触发 / 收入 / 终局）、放置奖励、地图奖励、终局计分
    abilities.ts    动物能力的名称、说明与单人替换
    query.ts        合法性检查、图标统计、候选枚举
    rules.ts        规则常量：收入表、计分换算、行动卡数值、奖励门槛
    maps.ts hex.ts buildings.ts   地图、六边形几何、建筑形状
    ai.ts           AI：模拟每个候选行动 + 两步前瞻，用局面估值打分
    content/        动物、赞助、保护项目、终局计分卡（原版功能数据）
  net/              联机：极简 MQTT 客户端（mqtt.ts）、房间协议（room.ts）、与界面的对接（online.ts）
  ui/               Preact 界面
tests/              规则单元测试、内容完整性、随机走法与 AI 完整对局、联机协议（内存服务器 + 丢消息）
```
